# Smart Clinic Management System - User Stories

## Admin User Stories

1. As an Admin, I want to manage user accounts so that I can control access to the system.

2. As an Admin, I want to manage doctors so that their information and availability are kept up to date.

3. As an Admin, I want to view and manage appointments so that I can maintain the overall appointment system.

4. As an Admin, I want to manage system functionality and user permissions so that the application remains secure and organized.

## Patient User Stories

1. As a Patient, I want to register and log in so that I can securely access the appointment portal.

2. As a Patient, I want to search for available doctors so that I can choose a suitable doctor.

3. As a Patient, I want to view available appointment slots so that I can select a convenient time.

4. As a Patient, I want to book an appointment so that I can schedule a consultation with a doctor.

5. As a Patient, I want to view my appointments so that I can keep track of my scheduled consultations.

6. As a Patient, I want to cancel or manage my appointments so that I can keep my schedule up to date.

7. As a Patient, I want to view my patient records so that I can access my medical information.

## Doctor User Stories

1. As a Doctor, I want to log in securely so that I can access my dashboard.

2. As a Doctor, I want to manage my availability so that patients can book appointments during my available times.

3. As a Doctor, I want to view my appointments so that I can manage my daily schedule.

4. As a Doctor, I want to view patient information so that I can prepare for consultations.

5. As a Doctor, I want to manage appointment status so that I can keep appointment information up to date.

6. As a Doctor, I want to create and manage prescriptions so that patients can receive appropriate medication information.
